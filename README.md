\# LocalAlert



LocalAlert is a mobile application designed to improve the reporting and communication of missing-person cases in South Africa.



\## Project Structure



\- `frontend/` – React Native / Expo mobile application

\- `backend/` – FastAPI backend

\- `database/` – Database-related files

\- `docs/` – Project documentation



\## Technologies



\- React Native

\- Expo

\- Python / FastAPI

\- PostgreSQL

\- REST API

\- JWT Authentication
